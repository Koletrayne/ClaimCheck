How Classroom Mode handles student data

What it does not collect

  • No student accounts, names, or email addresses
  • No student IDs, ages, or birthdays
  • No saved history of what students checked
  • No per-student analytics or tracking across sessions

What it does keep

  • The classroom’s own settings and access code
  • Totals for the whole class — usage and number of analyses
  • Error and performance logs needed to run the service

Usage is counted for the classroom as a whole, never per student. When a classroom ends, its access code stops working and open student sessions end. Full architecture and data-handling notes live in CLASSROOM_MODE.md in the ClaimCheck repository.
